## Installation ⬇️

- **Linux/MacOS**
  ```
  # Downloads the installer
  curl -sL "https://raw.githubusercontent.com/Static-Codes/BrowserAutomationMaster/refs/heads/main/src/Installers/UnixLike/install.sh" -o install.sh

  chmod +x install.sh # Give the installer executable privileges

  ./install.sh # Run as an executable file

  rm install.sh # Remove the installer
  ``` 

- **Windows**
  - Visit https://github.com/Static-Codes/BrowserAutomationMaster/releases/latest
  - Download the setup for your CPUs architecture, most users will be okay downloading the x64 windows build.

## Opening BAMM 🚀

- **MacOS:** `./bamm`

- **Linux/Windows:** `bamm`
